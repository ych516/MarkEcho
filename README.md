# MarkEcho · 回笺（官网）

这是 [MarkEcho](https://ych516.github.io/MarkEcho/) 的公开官网和下载通道。

- 介绍产品、提供 **Windows** 安装包下载
- 安装包发在本仓库 [Releases](https://github.com/ych516/MarkEcho/releases)
- **不含桌面应用源码**（源码在私仓）
- macOS 安装包在验证完成前不提供

## 网站

GitHub Pages 从 `main` 分支根目录发布：

https://ych516.github.io/MarkEcho/

下载按钮会读取 `releases/latest` 的 Windows 资源（`.msi` / `.exe`）。还没有 Release 时，按钮显示「即将发布」。

## 发布安装包

在私仓打出 Windows 安装包后，上传到本仓库的 GitHub Release，官网会自动挂上最新文件。
